# 国际化（i18n）

本页讲什么：界面语言（`ui.locale`）如何取值与加载、内置语言包覆盖哪些文案、如何放置自定义语言包，以及 UI 语言与模型回答语言的区别。当前实现只覆盖部分界面文案，完整范围见下文。

## 两套语言设置

| 用途 | 来源 | 说明 |
| --- | --- | --- |
| UI 界面语言 | settings 的 `ui.locale` | 只影响界面固定文案，不影响模型回答 |
| 模型回答语言 | 显式配置 > `KIANA_OUTPUT_LANGUAGE` > settings | 决定 system prompt 里的回答语言规则 |

- `ui.locale` 缺失或为空时，依次回退旧键 `language`、`"en"`；空串与纯空白视为未设置。
- 模型回答语言：显式配置（会话/SDK 参数）优先；其次是 `KIANA_OUTPUT_LANGUAGE`；最后读 settings：顶层 `output_language`，再读 `ui.outputLanguage` / `ui.output_language`。
- `en`、`en-us`、`english` 或空值不追加回答语言规则；`zh`、`zh-tw`、`ja`、`de` 等会在 system prompt 中追加“必须用该语言回答”的规则（大小写不敏感）。
- 两者互不影响：切换 UI 语言不会改变模型回答语言，反之亦然。

## UI 语言如何生效

- 交互模式启动时读取一次 `ui.locale`，从 `<agentDir>/locales` 与编译进二进制的语言包构造翻译器（`<agentDir>` 默认 `~/.kiana/agent`，可用 `KIANA_CODING_AGENT_DIR` 覆盖）。
- `/settings` → `Language` 只有 `English` 与 `简体中文` 两项。选择后写入**全局**设置文件 `~/.kiana/agent/settings.json` 的 `ui.locale`，立即重建翻译器并刷新待发消息与审批队列的标题/提示文案；状态行显示 `Language: <名称>`。
- 直接编辑 settings 文件后，`/reload` 不会重新应用 `ui.locale`（运行期设置的应用列表不包含该项）；需要重启 kiana。
- 启动时**不**读取 `KIANA_LANG` / `LC_*` 决定界面语言。代码中存在 `detect_locale_from_env()`（优先级 `KIANA_LANG` > `LC_ALL` > `LC_MESSAGES` > `LANG`，空值跳过，未识别回退 `en`），但当前没有生产调用点；设置这些环境变量不会改变界面语言。

## 内置语言与回退链

- 编译进二进制的语言包只有 `en.json` 与 `zh.json`，共约 20 个固定文案 key。
- 语言表声明 9 个代码：`en`、`zh`、`zh-TW`、`ja`、`de`、`fr`、`pt`、`ru`、`ca`。除 `en` / `zh` 外没有内置包，加载时回退英文内置包（逐 key 回退，最后回退 key 名本身）。
- locale 规范化：去掉首尾空白、`_` 换成 `-`、转小写、去掉 `.编码` 与 `@修饰`；`zh-TW` / `zh-HK` 归为 `zh-TW`，其余按代码或标准 id 前缀匹配（如 `zh_CN.UTF-8` → `zh`，`pt_BR` → `pt`）。
- `zh` 与 `zh-TW` 标记为 strict：语言包必须与英文 key 集合一致，且 `MUST_TRANSLATE_KEYS`（审批、模态框、待发消息等 12 个 key）必须真正翻译。该校验用于测试/CI，不影响运行期加载。

## 自定义语言包

- 用户语言包目录：`<agentDir>/locales`（默认 `~/.kiana/agent/locales`），文件名使用解析后的 locale 代码（如 `zh.json`；`zh_CN` 会解析为 `zh`），扩展名可为 `.json` 或 `.toml`。
- 用户包只覆盖其中提供的 key；未提供的 key 沿用内置包（如 `zh`），没有对应内置包的语言回退英文。用户包损坏时被跳过并记录诊断，不影响启动。
- JSON 结构：

```json
{
  "locale": "zh",
  "strict": true,
  "strings": {
    "approval.allow_once": "只允许一次"
  }
}
```

- TOML 只支持子集：`key = "text"`、`key = ["a", "b"]`、`[strings]` 段与 `#` 注释；只解析字符串与字符串数组，不执行代码。
- 未在语言表声明的代码也可以自建包（例如 `xx.json`）；此时其余文案回退英文。

## 当前覆盖范围

- 已接线的固定文案：待发消息（`Sending...` / `Failed to send: ...` / `Retry` / `Send timed out`）、审批卡（`Permission required`、危险提示、建议项、风险区标题）、模态框计数与提示（`Approval 1/N`、`Question 1/N`、提交/多选提示、设置标题）、审批队列标题。
- 审批卡的作用域值本身是固定英文（`this session` / `this machine` / `this project`），所以中文界面显示为 `总是允许（this session）` 等。
- 其余界面仍有大量英文常量：header/footer、设置面板项标签、选择器、状态行等。将 `ui.locale` 设为 `zh` 不会让整个界面变成中文。

## 限制与未验证

- `KIANA_LANG` / `LC_*` 检测函数存在但未接线（见上），当前不会影响 UI 语言。
- 自定义语言包的实际加载未做端到端实测（未验证）；代码路径为 `<agentDir>/locales/<locale>.{json,toml}`。
- `zh-TW`、`ja`、`de` 等语言没有随包语言文件；不提供用户语言包时会显示英文。
- `/settings` 的 `Language` 只提供 `English` / `简体中文`；其他语言需要直接编辑 settings 的 `ui.locale` 或放置用户语言包。
